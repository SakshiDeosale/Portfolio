## 📥 Installation

Clone the repository

```bash
git clone https://github.com/SakshiDeosale/Portfolio.git
```

Navigate to the project folder

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm start
```
